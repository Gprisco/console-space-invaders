# Console Space Invaders

A Space Invaders game that runs in your terminal. Defend the Playfield: dodge and shoot down each Wave of Aliens before they reach you.

![Gameplay demo](assets/demo.gif)

## Run

```sh
cargo run
```

Needs a real terminal (uses raw mode + alternate screen).

Controls: `←`/`→` move, `Space` fire, `q`/`Esc` quit.
